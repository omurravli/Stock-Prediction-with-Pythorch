# Stock Price Prediction with PyTorch

This project inspects stock price time-series forecasting with Long Short-Term Memory(LSTM) and Gated Recurrent Unit (GRU) models implemented using PyTorch

## Project Objectives

- Learn the fundamentals of machine learning and time-series forecasting
- Prepare historical stock price data using Pandas
- Build LSTM and GRU regression models using PyTorch
- Evaluate the models using MSE, RMSE, and MAE
- Compare model performance and training time
- Compare the deep learning models against a naive baseline
